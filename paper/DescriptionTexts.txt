1 (Fig. 1) - Block diagram of SelectNorm. Upper lane, inference: the Arabizi input x goes to the first pass of the frozen classifier and to the conservative normaliser with metadata, whose costs c0 and cT are sunk; both feed the decision features z, then the factorised benefit, then cost-aware routing. If g is 0, the first-pass prediction is returned; if g is 1, a dashed optional second pass on T(x), with avoidable cost c1, produces the prediction. Lower lane, offline: the disagreement estimator, the conditional advantage estimator, the threshold and the optional few-label recalibration.
2 (Fig. 2) - Four panels in a two-by-two grid, one per test set, plotting macro-F1 against estimated inference cost. Coloured lines with distinct markers and line styles show SelectNorm-adapt with tuned and Bayes thresholds, the direct-gain router B4 and confidence thresholding B3 at six values of lambda, with error bars; single markers show always normalising B1, the two-view ensemble R and, where in range, the original view B0. A note beneath each panel gives B0 when it lies below the plotted range.
3 (Fig. 3) - Dot plot with four panels in one row, one per encoder (mE5, XLM-R, LaBSE, MARBERTv2), and one row per test set S3 to S6. Each row shows three AUC values with 95 percent intervals: circles for the disagreement estimator on unlabelled target text, between 0.62 and 0.74; squares for the advantage estimator trained on source labels, mostly between 0.54 and 0.71, with XLM-R at 0.45 and 0.44 on S5 and S6; triangles for the target-label cross-validated reference, between 0.53 and 0.68. A dashed vertical line marks AUC 0.5.
